Strategy parameters

The numbers the algorithm trades on. Every edit is checked against the rules that must hold — a ladder floor above its own trigger is refused, not saved.

Administration

Operators

Who can sign in, and what each of them is allowed to do. A viewer can read the P&L; an operator can start and stop the bot; a super admin can also manage people and replace the algorithm.

Algorithm

Replace the trading logic entirely. An upload is checked before it can be activated — syntax, entry point, every import resolving, and a sandboxed import that runs its module-level code without touching your broker.
Writing a new algorithm?
Copy the brief, paste it into a Claude chat, and describe the strategy you want. It carries the complete event contract — every field the deck, Trades and Reports read — so what comes back reports properly instead of running silently.
